# PRAHARI Synthetic Dataset — Disclaimer

## About This Dataset

This dataset was generated for the **PRAHARI hackathon prototype demonstration** only.

### What Is Real

The following are real, publicly available administrative and geographic facts:

- **District names** (Bangalore Urban, Mysuru, Dakshina Kannada, Belagavi, Kalaburagi) — official Karnataka revenue district names
- **Police station locality names** (Whitefield, HAL, Bellandur, Indiranagar, Devaraja, Krishnaraja, etc.) — real police station localities/jurisdictions as publicly listed by the Karnataka State Police
- **Vehicle registration series** (KA-01 through KA-05 for Bangalore Urban, KA-09 for Mysuru, KA-19/21/62/70 for Dakshina Kannada, KA-22/23/24/49 for Belagavi, KA-32 for Kalaburagi) — official series assigned by the Karnataka Regional Transport Authority, publicly available

### What Is Entirely Fictional

**Every single data record in this dataset is entirely fictional and synthetic**, specifically:

- All **person names** (criminals, suspects, wanted persons, officers, victims, witnesses, vehicle owners) — invented, do not represent any real individual
- All **FIR (First Information Report) records** — invented incident types, dates, locations, and details
- All **case records** — invented case numbers, statuses, and assignments
- All **criminal and offender profiles** — invented names, prior offense summaries, and offense counts
- All **wanted person entries** — invented charges, reward amounts, and descriptions
- All **officer records** — invented names, badge numbers, and beat assignments
- All **vehicle registration plate numbers** — invented alphanumeric combinations in valid Karnataka format; any resemblance to a real registered vehicle is coincidental
- All **CCTV detection records** — invented camera IDs, timestamps, detected plate numbers, and confidence scores; no actual surveillance footage or imagery is included
- All **evidence log entries** — invented descriptions and chain-of-custody details
- All **reward amounts** — clearly labeled as illustrative/synthetic values (e.g., "₹25,000 (synthetic)")

### What This Dataset Is NOT

This dataset:
- Does **not** represent any real crime, real criminal record, or real police case
- Does **not** represent any real individual's personal information
- Does **not** contain any real investigation data, surveillance data, or law enforcement intelligence
- Was **not** derived from, and should **not** be confused with, any Karnataka State Police operational database

### Purpose

This dataset exists solely to populate the PRAHARI demo system with realistic-looking structured data so that the data fusion, risk scoring, and hotspot mapping modules can be demonstrated to judges at the hackathon. It has no operational, legal, or investigative significance whatsoever.
